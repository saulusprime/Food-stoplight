Colonne riconosciute

L'ordine non conta e le colonne mancanti si possono omettere: serve solo «Alimento».

  • Alimento (anche «Nome»), Categoria
  • Kcal, TEF (Kcal), TEF (%), Kcal Nette
  • Fruttosio, Fibre: il rapporto F/F viene sempre ricalcolato
  • Rischio Diabete, Colesterolo, Malassorbimento, Metabolico, Tumorale
  • ID: per aggiornare proprio quella riga (presente nei file esportati)

Valori accettati

  • Numeri con virgola o punto decimale, anche con «%» o l'unità («5,9 g»).
  • Livelli: Trascurabile, Basso, Medio, Alto, anche preceduti da emoji («🔴 Alto»). Protettivo e Neutro valgono Trascurabile, Elevato e Aumentato valgono Alto.
  • Celle vuote, «-», «N/A», «nd»: valore assente.
  • Per modificare i dati in Excel: esporta dalla tabella, modifica il file e reimportalo con «Aggiorna o aggiungi».
